# v0.1.1 Release Repair

## Incident

The public v0.1.0 ARM64 macOS DMG matched its GitHub SHA-256 and passed
`hdiutil verify`, but the contained app failed strict code-signing validation.
Gatekeeper consequently described the app as damaged. The release was returned
to draft.

The same release exposed electron-updater `.yml` metadata and `.blockmap`
files as user-facing assets. Matrix jobs also overwrote shared updater metadata,
leaving the Windows feed ARM64-only and the macOS feed x64-only.

## Requirements

- Ship the repaired release as v0.1.1; never move or reuse the v0.1.0 tag.
- Promote every repository change through working branch -> `dev` -> `main`.
- Publish only user-installable desktop assets. Never upload `.yml` or
  `.blockmap` files to GitHub Releases.
- Use these exact installer names:
  - `PromptBranch-0.1.1-macos-arm64.dmg`
  - `PromptBranch-0.1.1-macos-arm64.zip`
  - `PromptBranch-0.1.1-macos-x64.dmg`
  - `PromptBranch-0.1.1-macos-x64.zip`
  - `PromptBranch-0.1.1-windows-arm64.exe`
  - `PromptBranch-0.1.1-windows-x64.exe`
  - `PromptBranch-0.1.1-linux-arm64.AppImage`
  - `PromptBranch-0.1.1-linux-arm64.deb`
  - `PromptBranch-0.1.1-linux-x64.AppImage`
  - `PromptBranch-0.1.1-linux-x64.deb`
- macOS tagged builds must fail before packaging if Developer ID or
  notarization credentials are absent.
- macOS CI must verify the complete app signature, Gatekeeper assessment, and
  notarization ticket before an installer can reach the release publisher.
- Build jobs must never publish directly. A single dependent publisher job may
  upload only the installer staging directories after every architecture passes.
- Keep the new GitHub release as a draft until installers downloaded from the
  draft are independently validated on their target operating systems.
- Release notes must map each filename to its operating system and architecture
  and explain that automatic desktop updates are disabled for this release.

## Acceptance evidence

- Artifact-policy tests fail on missing, misnamed, or forbidden assets.
- Workflow tests prove fail-closed macOS signing and installer-only publishing.
- Full tests, typecheck, build, and license checks pass.
- CI architecture checks pass for all six matrix jobs.
- Downloaded macOS DMGs match GitHub digests and pass `hdiutil`; their app
  payloads pass `codesign`, `spctl`, and `stapler` validation.
- Downloaded Windows and Linux installers are exercised on their target runners.
